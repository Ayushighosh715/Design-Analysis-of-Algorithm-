## Problem Statement ##
Write a program to multiply two matrices A and B. The program should read their dimensions and elements, check whether matrix multiplication is possible, and display the resulting product matrix.
---

#Algorithm ##
1. Read the dimensions r1 × c1 of matrix A and input its elements.
2. Read the dimensions r2 × c2 of matrix B.
3. Check if c1 == r2.
4.If not, print "Invalid input" and stop.
Input the elements of matrix B.
5.For each row i of A and column j of B:
Set C[i][j] = 0.
For k = 0 to c1-1, calculate:
C[i][j] = C[i][j] + A[i][k] × B[k][j]
6. Print the resulting matrix C of size r1 × c2.
7. Stop.

-------
## Code## 
#include <stdio.h>

int main() {
	int r1, c1, r2, c2;
	int a[100][100], b[100][100], c[100][100];

	scanf("%d %d", &r1, &c1);

	for (int i = 0; i < r1; i++)
		for (int j = 0; j < c1; j++)
			scanf("%d", &a[i][j]);

	scanf("%d %d", &r2, &c2);

	if (c1 != r2) {
		printf("Invalid input");
		return 0;
	}

	for (int i = 0; i < r2; i++)
		for (int j = 0; j < c2; j++)
			scanf("%d", &b[i][j]);

	for (int i = 0; i < r1; i++) {
		for (int j = 0; j < c2; j++) {
			c[i][j] = 0;
			for (int k = 0; k < c1; k++)
				c[i][j] += a[i][k] * b[k][j];
		}
	}

	for (int i = 0; i < r1; i++) {
		for (int j = 0; j < c2; j++)
			printf("%d ", c[i][j]);
		printf("\n");
	}

	return 0;
}
