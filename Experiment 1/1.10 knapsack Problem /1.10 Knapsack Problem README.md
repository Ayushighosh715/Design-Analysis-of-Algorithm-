## Problem Statement ##
Write a program to implement the 0/1 Knapsack Problem. Given N items, each having a value and a weight, and a knapsack with capacity W, determine the maximum total value that can be obtained by selecting a subset of the items such that the total weight does not exceed W. An item can either be included completely or excluded completely from the knapsack. Fractional selection of items is not allowed.

## Algorithm ##
Start.
Read the number of items n.
Read the value of each item.
Read the weight of each item.
Read the knapsack capacity.
Create a DP array dp of size capacity + 1.
Initialize all elements of dp to 0.
For each item, repeat the following steps.
Traverse the capacity from capacity down to the weight of the current item.
Calculate the value by adding the current item's value to dp[w - weight[i]].
If the calculated value is greater than dp[w], update dp[w].
Continue the process for all items.
The maximum value is stored in dp[capacity].
Print dp[capacity].
Stop.

## Code ## 
#include <stdio.h>

int main() {
	int n, capacity;

	scanf("%d", &n);

	int value[n], weight[n];

	for (int i = 0; i < n; i++)
		scanf("%d", &value[i]);

	for (int i = 0; i < n; i++)
		scanf("%d", &weight[i]);

	scanf("%d", &capacity);

	int dp[capacity + 1];

	for (int i = 0; i <= capacity; i++)
		dp[i] = 0;

	for (int i = 0; i < n; i++) {
		for (int w = capacity; w >= weight[i]; w--) {
			if (dp[w - weight[i]] + value[i] > dp[w])
				dp[w] = dp[w - weight[i]] + value[i];
		}
	}

	printf("%d", dp[capacity]);

	return 0;
}
